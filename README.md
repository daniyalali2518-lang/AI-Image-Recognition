# Real-Time Image Classification and Recognition

This assignment demonstrates the practical implementation of machine learning through image recognition. It uses a webcam to capture live images and an AI-trained model to identify and classify objects. The program processes webcam frames continuously and displays prediction labels along with their confidence scores. It introduces the fundamentals of AI-powered visual recognition and real-time classification.

1. Image Model Initialization:
   Loads the trained Teachable Machine model and its metadata to prepare the image classification system.
2. Webcam Recognition:
   Activates the webcam, captures live frames, and uses the trained AI model to classify images and display prediction results.
